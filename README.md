Sales-analysis-dashboard-Power-BI

Objective

To analyze sales performance across products, regions, and time in order to identify trends, high-performing segments, and areas of improvement.

 Dataset

1) 3300 records sales dataset with transactional records
2) Includes revenue, product categories, and regional data
3) Processed and structured for analysis

Tools & Techniques

Power BI
1) Data Modeling (relationships between tables)
2)  DAX (for calculated measures and KPIs)
3) Interactive Dashboard Design using slicers

Key Features

1) Built an interactive dashboard with filters for dynamic analysis
2) Designed KPI indicators to track overall sales performance
3) Enabled drill-down analysis by region and product category
4) Structured visuals for quick and intuitive insights

 Key Insights

1) Identified top-performing products contributing most to revenue
2) Highlighted regional variations in sales performance
3) Observed trends and patterns across time periods
